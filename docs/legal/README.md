## 弁護士・行政書士に必ず確認すべき論点（エンジニア側からの申し送り）

### 論点1: 出会い系サイト規制法の該当性と年齢確認の方法
ハピマリは見知らぬ異性同士がメッセージ交換できるため、**インターネット異性紹介事業に該当する
可能性が高い**。該当する場合、開業前の届出と18歳未満を利用させない年齢確認が法的義務。
- 現在の実装: 登録は**35歳以上**（生年月日をDB制約で検証）＋**本人確認書類の提出と管理画面での審査**
  （身分証・収入証明・独身証明の3種）。
- 確認点: この方式が同法の求める年齢確認要件を満たすか。書類の種類・保存期間の指定はあるか。

### 論点2: 退会後のデータ保存 ★要決定
**現在の実装では、退会してもデータは物理削除されません**（アカウントを「退会済み」状態に変更し、
プロフィールや過去のやり取りはDBに残る設計）。これは通報・紛争対応や不正の再登録防止に有用な一方、
個人情報保護法は「利用する必要がなくなった個人データの消去」を求めています。
- 決めていただくこと: **退会後の保存期間**（例: 6か月・1年）と、その後の扱い（完全削除 or 匿名化）。
- 決定後、エンジニア側で自動削除の実装が必要です（現状は未実装）。

### 論点3: 音声通話機能の扱い ★要確認
現在の通話機能は**モック実装（呼び出しのUIは動くが音声は流れない）**です。
- 有料プランの「役務内容」に通話を含めて表示すると、実態と異なる恐れがあります。
- 公開時に音声を実装しない場合は、特商法表記・利用規約から通話の記述を外すか、
  「準備中」と明記する必要があります。ドラフトでは**通話を含めない**書き方にしています。

### 論点4: サブスクの自動更新と中途解約
男性課金は3ヶ月・6ヶ月の長期プランがあります。特商法は定期購入について
**自動更新の有無・解約方法・解約期限**の明示を強く求めています。
- 決めていただくこと: ①自動更新するか ②中途解約時の返金の可否（原則不可とするのが一般的）
  ③解約の受付方法と期限（例: 次回更新日の24時間前まで）
- 現在の課金はモックで期間管理が未実装。Stripe実装（M7）時に、ここで決めた仕様を反映します。

### 論点5: 位置情報の取り扱い
距離マッチングのため位置情報を取得しますが、**座標は約1km単位に丸めて保存し、他の利用者には
「5km以内」等の帯域表示しか返しません**（三点測位で自宅を特定されないための設計）。
- 確認点: この粒度でも「個人関連情報」としての同意取得が必要か、取得同意の文言が十分か。

### 論点6: 写真・本人確認書類の保管
写真は非公開ストレージに保存し、**運営の事前審査を通過するまで他の利用者には表示されません**。
本人確認書類は利用者間で一切共有されず、運営のみが閲覧します。
- 確認点: 本人確認書類（機微情報を含みうる）の保存期間・アクセス記録の要否。
