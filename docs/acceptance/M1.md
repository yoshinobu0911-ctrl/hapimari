## 改訂: 価値観マッチング対応（2026-07-06 ユーザーフィードバック）

> 「死別・離婚などは最初の一覧に出さない。価値観マッチングとして、カードは写真・名前・年齢・相性の4つ。文字は大きく、写真に重ねない」

対応内容:

1. **価値観タグ30個**を導入（`packages/shared/src/value_tags.ts`）。
   競合（マリッシュのグループ/Pairsのマイタグ/youbrideの価値観項目）に共通する
   6カテゴリ（結婚・家族観 / お金・暮らし / 住まい方 / 連絡・会い方 / 休日・趣味 / 性格）で再構成。
2. **相性スコア**（`compatibility.ts`）: タグ一致50% + 時間帯20% + 結婚意向の近さ20% + 子ども/再婚への相互理解10%。
   表示は40〜98%。単体テスト6件（単調性・レンジ・理解宣言の影響等）。
3. **discoverカード刷新**: 写真（文字を重ねない）・名前(20pt)・年齢(18pt)・相性%(20pt/プライマリ色)の4点のみ。
   結婚歴・居住地・子どもの有無・認証バッジはカードから削除（詳細画面=M3で表示）。
   相性の高い順にソート。異性のみ表示に変更。
4. オンボーディングstep3とプロフィール編集に**タグ選択チップUI**を追加（3つ以上必須）。
5. DB: `profiles.value_tags text[]` migration + seed20名とテストユーザーにタグ付与。

検証: E2Eユーザー（女性・タグ5個）のdiscoverで「たかし 48歳 相性88%」を筆頭に相性降順で
男性12名のみが表示されることを確認。テスト24件成功・tsc/biomeクリーン。

## 特記事項（M1での発見と対応）

1. **Supabaseローカルの既定GRANT欠如**: profiles への SELECT が 403 になる問題が発生。
   現行スタックでは public テーブルへの DML GRANT が自動付与されないため、
   `20260706010000_explicit_grants.sql` で明示付与（詳細は QUESTIONS.md Q4）。
2. **都道府県選択を全件描画に変更**: FlatList の仮想化が47件でも描画を遅延させるため
   ScrollView + map に変更（47件なら性能影響なし・確実に全件表示）。
3. Expo SDK 57 では `Tabs` は `expo-router/js-tabs` からのimportが推奨（本体からは非推奨警告）。
4. Alert.alert が react-native-web で動作しないため、確認ダイアログは
   `lib/confirm.ts` でWeb/ネイティブを吸収（SPEC §2「破壊的操作に確認ダイアログ」対応）。
