## 今回保証しないこと（オーナー指示3・設計の受け入れ条件16）

- 凍結・退会・プロフィール削除の**前に**発行済みの署名URLは、最長60分有効なまま残る（即時失効は別課題）。
- 端末に表示済み・キャッシュ済みの画像、スクリーンショット。
- 在籍中に copy API で自分のフォルダへ複製した他人の写真は、本人フォルダ扱いで読めるまま残る（今回の実測でも、在籍中の copy は成功した。追加の発見として報告書に記載）。
- 本人確認前（is_verified=false）の active 利用者は、在籍中として他人の写真を読める（決定の範囲外）。
