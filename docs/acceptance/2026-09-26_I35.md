## 前提（受け入れの条件・重要）

**本番アプリは未デプロイのため、実際のプロキシのヘッダは未確認。** Vercel 公式ドキュメントの次の記述を前提にした（2026-09-26 確認）:
- HTTP の要求は CDN が必ず 308 で HTTPS へ転送し、無効化できない（docs/cdn-security/encryption）。
- `x-forwarded-proto` は本番では通常 `https`（docs/headers/request-headers）。

この前提が崩れる配信先（Vercel 以外・ヘッダを付けないプロキシの前置）では、管理画面が全面 403 になる。
