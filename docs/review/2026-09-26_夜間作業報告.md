## 6. push についての推奨

- **全件 push してよい（推奨）**。理由: 本番（DB・Edge Functions・アプリ配信）には何も反映しておらず、push は GitHub 上のコードが進むだけ。すべてローカルで検証済み。
- ただし **本番反映（`db push`・`functions deploy`）はまだ行わないこと**。先に (1) 決済の must 4件、(2) like 関数の起動不具合 を直す必要がある。反映するときの順番は `docs/release_web.md` STEP 2（今夜更新）: Edge Functions → migration → アプリ。

## 9. 引き継ぎメモ（次の担当向け）

- snapshot の再生成は以後 **`pnpm exec supabase db dump --local -s public -s storage -s private -f supabase/schema.generated.sql`**（I29 で private スキーマを新設したため）。
