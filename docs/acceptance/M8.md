## B. 未実施（Agora実キーの設定後に実施すること）

`supabase/functions/.env` に `AGORA_APP_ID` / `AGORA_APP_CERTIFICATE` を設定後、設計書 §7 の手順で:

1. 2ブラウザ（通常＋シークレット）でマッチ済みシードユーザー同士の発着信 → **双方向に音声が流れる**
2. マイク許可を拒否 → 呼び出しが始まらず「マイクの使用が許可されていません…」表示
3. `AGORA_TOKEN_TTL_SECONDS=120` で2分後に自動切断（＝15分上限のサーバー側強制の確認）
4. 通話後に calls ログ（開始・終了・秒数）が記録されている
5. 本番デプロイ時: `supabase secrets set` でも同じ2値を設定（launch_checklist ②-20）

## C. 委託エンジニアレビュー（(C) 本番公開前）で必ず見てほしい点

1. `agora-token` の資格チェック（当事者・ブロック・相手のstatus）に迂回が無いこと
2. トークンTTL（既定960秒）による15分制限のサーバー側強制
3. App Certificate がサーバー側にしか存在しないこと（アプリ・Gitに無い）
4. `.web.ts` 分割によりネイティブへ Web SDK が混入しないこと
