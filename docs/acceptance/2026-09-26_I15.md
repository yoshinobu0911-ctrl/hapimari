## 前提

- SQL テストは送り主 1,350人（auth.users と profiles）をトランザクション内で作り、最後に rollback する。DB には何も残らない。
- 1日の上限 100 は SQL に直書き（`FEMALE_DAILY_LIKE_LIMIT` と同値）。TS 側の定数と自動で突き合わせるテストは、`@types/node` の追加が必要になるため作っていない（依存追加禁止）。変更時は migration と SQL テスト #1 で気づける。
- `like_visibility.ts`（TS 版の割当）と既存の Vitest は残した（画面からは使わなくなった）。
