## 前提

- REST 確認の後片付け: 使い捨てマッチの user_events → messages → matches の順に削除。user_events の総数が計測前（4件）に戻ったこと、マッチが0件になったことを確認。既存マッチには何も足していない（設計の「既存マッチに古い1件を足す」手順は、既存マッチにもともと古いメッセージがあったため不要だった）。
- 型の再生成は PowerShell の `Out-File -Encoding utf8NoBOM`、snapshot は `db dump -s public -s storage`（I29 以降は `-s private` を追加すること）。
