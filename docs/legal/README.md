## 弁護士・行政書士に必ず確認すべき論点（エンジニア側からの申し送り）

### 論点1: 出会い系サイト規制法の該当性と年齢確認の方法
ハピマリは見知らぬ異性同士がメッセージ交換できるため、**インターネット異性紹介事業に該当する
可能性が高い**。該当する場合、開業前の届出と18歳未満を利用させない年齢確認が法的義務。
- 現在の実装: 登録は**35歳以上**（生年月日をDB制約で検証）＋**本人確認書類の提出と管理画面での審査**
  （身分証・収入証明・独身証明の3種）。
- 確認点: この方式が同法の求める年齢確認要件を満たすか。書類の種類・保存期間の指定はあるか。
- **追記（2026-08-25）**: 届出書「児童でないことの確認の実施方法」の説明・記載文例・
  確認前に可能な操作（閲覧・一言メッセージ付きいいね・音声通話）の論点を
  [age_verification_description.md](age_verification_description.md) にまとめた。行政書士との面談時はこれを渡すこと。

### 論点2: 退会後のデータ保存 ✅決着（2026-07-30・実装済み）
**オーナー判断: 退会後90日で個人を特定できる情報をすべて削除し、学習用の特徴量だけを匿名で無期限保持。**
メールアドレスはハッシュ値のみ無期限保持（配信除外・再登録禁止・ブロック引き継ぎ）。写真も削除する。
再登録は退会から7日後より可（新規アカウント扱い・過去データは復元しない）。
実装: migration 20260730120000 / 管理画面「データ保持ジョブ」/ 検証記録 docs/acceptance/M6_7.md

<details><summary>旧記載</summary>

### 論点3: 音声通話機能の扱い ✅決着（2026-07-30）
**オーナー判断: 通話は他社標準装備のため例外なく提供する。** よって公開前に音声通話を本実装する
（現在はモック）。書面には通話を含める記載に更新済み（特商法の役務内容・利用規約 第8条の2）。
開発タスクとして launch_checklist に追加。外部の音声通話サービス契約が前提（人間タスク）。

**追記（2026-08-19・要レビュー）**: 実装方式は Agora（アプリ内VoIP）に決定し、
**通話は課金の対象外（無料の男性会員も利用可）**とオーナーが決定した
（`docs/decisions/2026-08-19_通話はAgora_課金ゲートなし.md`）。
現在の tokushoho.md は「有料プランに含まれる機能」に音声通話を列挙しているため、
**レビュー時に『無料の範囲でも通話可』へ記載を整合させる**こと。録音は行わない。

### 論点5: 位置情報の取り扱い
距離マッチングのため位置情報を取得しますが、**座標は約1km単位に丸めて保存し、他の利用者には
「5km以内」等の帯域表示しか返しません**（三点測位で自宅を特定されないための設計）。
- 確認点: この粒度でも「個人関連情報」としての同意取得が必要か、取得同意の文言が十分か。

### 論点6: 写真・本人確認書類の保管
写真は非公開ストレージに保存し、**運営の事前審査を通過するまで他の利用者には表示されません**。
本人確認書類は利用者間で一切共有されず、運営のみが閲覧します。
- 確認点: 本人確認書類（機微情報を含みうる）の保存期間・アクセス記録の要否。
