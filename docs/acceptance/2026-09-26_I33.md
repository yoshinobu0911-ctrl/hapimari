## 前提

- 再現スクリプトは分類と状態判定を写して実行した（関数そのものは vitest で検査済み）。
- DB の一時変更（seed13 の is_verified、01→13 のブロックと block_created イベント）は戻した。送信は失敗のみで messages への書き込みは0件。user_events 4件のまま。

## 追加の発見（直していない）

- **退会した相手にもメッセージを送れる**。相手（seed14）を `withdrawn` にした状態で seed02 が REST で送ると 201 で保存された。messages の INSERT ポリシーは「当事者・非ブロック・送信資格あり」で、相手の在籍を見ていない（画面は相手が退会すると「表示できないユーザー」になるが、送信欄は残る可能性あり）。計測で入った1件とイベントは削除済み。

## 翌朝オーナーに見てほしい点

- 送信失敗時の文言が原因ごとに変わる。とくに男性の有料プラン期限切れでは、従来の「本人確認の状態をご確認…」ではなく「有料プランの有効期限が切れているため送信できません。プランの画面からご確認ください。」になる。
