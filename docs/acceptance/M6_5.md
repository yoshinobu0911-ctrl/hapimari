## 相性計算の変更（判断#4）

- 旧: 価値観タグ45% / 距離15% / 会える時間帯15% / 結婚観15% / **事情への理解10%**
- 新: 価値観タグ **50%** / 距離16.7% / 会える時間帯16.7% / 結婚観16.7%（理解項目を除外し比例再正規化）
- 理由: 他人の子ども情報・理解宣言は profiles_public から取得できなくなったため。R3廃止（子持ち配慮はしない）方針とも整合。
- 距離不明時に距離を除いて再正規化する挙動は従来どおり。
