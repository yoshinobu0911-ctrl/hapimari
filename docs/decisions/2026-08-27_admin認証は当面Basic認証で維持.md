# 2026-08-27: admin本格認証（個別ログイン）は当面見送り

## 決めたこと
管理画面の認証は、当面**現行のBasic認証（共有パスワード1つ）のまま**とする。
Supabase Authベースの個別ログイン（M7で対応予定だったが未実施だった項目）は実装しない。

## 理由
運営スタッフが現時点でオーナー1名のみのため、「誰が審査したか」を個別に区別する必要がない。
個別ログインを導入する複雑さに見合うメリットが今はない。

## 影響
- `docs/launch_checklist.md` #9・`docs/acceptance/M6_5.md`のM7送り項目・`docs/review/2026-07-21_M6_5レビュアー返信.md`の該当記述は、
  「未実装」ではなく「当面の意図的な仕様」として扱う。
- `review_verification`のreviewed_byは、スタッフが増えて個別ログインを導入するまで実質的にnullのまま運用する（機能上の問題ではない）。

## 再検討のタイミング
運営スタッフが2名以上になった時点で、個別ログイン導入を再検討する。
