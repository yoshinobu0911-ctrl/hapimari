## 前提

- `functions serve --env-file <スクラッチ領域の dummy ファイル>`（AGORA の2値は 32 文字の x）で起動。**リポジトリ内に .env 系ファイルは作っていない**（設計の `.env.agora-dummy` 案の代わりにリポジトリ外のファイルを使用）。
- Edge Runtime 起動のため `abuse_words.ts:8` の import を一時的に `.ts` 付きにした（コミットしていない）。
- DB の一時変更（service_role の実行権の revoke→grant、blocks 行の挿入→削除、seed13 の is_verified）はすべて戻した。後片付け確認: `is_match_blocked` の proacl = `{postgres=X, authenticated=X, service_role=X}`（snapshot と同じ）、blocks 0件、SQL 全スイート合格。
