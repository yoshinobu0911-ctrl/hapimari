# 受け入れ記録: like 関数が Edge Runtime で起動しない不具合の修正（2026-09-26）

- 実装: Claude Opus 5.5。オーナー指示（2026-09-26「③を直してください」＝夜間作業報告 確認事項4 の推奨B）
- 人間レビューの段階: (B) MVP 完成時。暴言フィルタ（不正ユーザー対策）の置き場所の変更。判定内容は不変

## 原因

`packages/shared/src/abuse_words.ts`（2026-09-20 `2a7c842`）が `import { normalizeForFraudCheck } from './fraud_words'` と**拡張子なし**で import していた。Edge Runtime（Deno）は拡張子なしの相対 import を解決できず、`supabase functions serve` が `failed to read file: open packages/shared/src/fraud_words` で全関数まとめて起動しなかった（本番の `functions deploy like` も同じ理由で失敗する見込みだった）。

## 変更

| ファイル | 内容 |
|---|---|
| `packages/shared/src/fraud_words.ts` | 暴言辞書 `ABUSE_WORDS`・`findAbuseWords`・`containsAbuseWord` を移設（中身は一字一句同じ。同じファイル内の正規化関数を使う） |
| `packages/shared/src/abuse_words.ts` | 再公開だけにした（アプリ・テストの import 先を変えないため）。Edge Function から読まない旨を明記 |
| `supabase/functions/like/index.ts` | `findAbuseWords` を `fraud_words.ts` から読む |
| `docs/release_web.md` | 既知不具合の警告を、再発防止の注意書きに置き換え |

Edge Function が読む shared のファイル（constants・fraud_words・like_rules・subscription-plans）に、相対 import が1つも無いことを grep で確認した。

## 確認方法と結果

| 項目 | 結果 |
|---|---|
| Edge Runtime の起動 | ✅ **一時パッチなし**で `functions serve` が5関数とも起動 |
| like の応答 | ✅ I10 で記録した8ケース（未確認403×4・詐欺語400・自分400・不存在404・通常200）と**完全一致** |
| 暴言フィルタ | ✅ 一言「死ね」→ 400 `abuse_message`「一言メッセージに使用できない表現が含まれています（死ね）…」 |
| 5関数の基本応答 | ✅ I17 の計測と完全一致 |
| vitest・tsc・biome | ✅ 121件（暴言辞書のテスト5件を含む）／tsc shared・mobile・admin exit 0／biome エラー0 |

計測で入った DB の変更（いいね・イベント・006 の本人確認状態）は戻した（likes 11件・user_events 4件）。
